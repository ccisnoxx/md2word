# 参数表数值列归属检查设计

## 表格语义

由 [Canonical Grid 校验器](../../../app/services/tables/validator.py) 读取源表格单元格、矩形和物理列。优先消费显式或已绑定复核的表头。真实样本的 HTML 只使用 `td`，因此在表格片段顶部可用完整、独立、规范化的参数列标签序列识别该规则所需的局部表头。局部识别结果只供此校验使用。

- 标签使用源 run 文本，按大小写、空白和既有英文标点别名归一。支持有序的 MIN/TYP/MAX、MIN/MAX、LOW/NOM/HIGH、最小/典型/最大。每个叶子标签各占一个物理列。有多组时按顶层合并标题的范围和物理索引定位。续表只有在既有来源绑定和列映射足以证明对应关系时才继承分组。
- 只检查表头之后的源数据单元格。其横向区间与同一个已识别组中的至少两个数值列相交，并且源内容是可识别的技术数值时，记录一项 `table_semantics:value_column_span_ambiguous`。使用保守、有界的全值匹配识别小数、符号和技术数值。忽略空白、表头、标题、条件文字与纯竖向 rowspan。合法共用数值若无法从输入证明其意图，交由审核确认。
- 复用源 Grid 的 fragment、cell 和 row 身份。Word 继续按已冻结计划投影输入的 rowspan/colspan 和内容。[Word 表格合同](../../spec/backend/word-generation-rules.md#table-001-原生可编辑表格与-span-保真)

三个真实输入没有单元格级几何。本期交付跨列歧义规则。未来若接到可信几何，需绑定同一源 PDF、页、表、行、单元格与可靠的数值列边界，并排除压线或多列覆盖；可信几何唯一支持的列若与 HTML 的列归属冲突，再产出 `table_semantics:value_column_binding_mismatch` 并走现有质量阻断。包中表格外框、合并框中心和离线人工标注均不足以作为运行时单元格 bbox。

## 证据与报告

复用 [TableValidationReport](../../../app/services/tables/quality.py) 和 [表格证据](../../../app/services/tables/evidence.py) 的受控规则码、严重度、定位和产物身份。疑似项为质量 warning。沿现有表格质量贡献接入，保留可下载内部 DOCX。此异常属于输入的技术语义风险，Word 与原 Grid 一致时渲染完整性仍成立。

质量详情按当前结果和现有权限提供结构化条目。包含稳定表格、片段和单元格标识、源页、源内行、物理列区间、规范化列名及分组定位，以及有界的数值文本。单位来自同一数据行已绑定的单位列（含有效 rowspan）或单元格值，无法确认时省略。表格标题不可用时使用稳定表 ID 和源页上的位置。Word 输出行映射可复用既有 fragment 输出信息。具体值只出现在授权的内部详情，任务列表、公开摘要、日志和审核记录只保留固定码、计数与摘要身份。[表格质量路由](../../../app/domains/document_jobs/quality_review_router.py) · [质量详情投影](../../../app/domains/document_jobs/quality_review_projection.py)

新增字段在无数据时沿用旧序列化形状。老报告按原校验合同解释，新报告明确标识执行了本规则。评估时核对证据版本、验证摘要、已有 hash 及重算路径。历史输入未评估此规则时不展示为本规则通过；上线前已发布记录按原快照读取。

## 产物审核与发布

复用现有授权复核操作及追加式审核记录。一轮明确的「已对照源 PDF 核对本报告全部疑似项，当前 DOCX 可接受」确认绑定当前表格质量证据摘要和现有主件绑定。批准请求带当前报告摘要，审核写入在现有同任务原子边界以当前选中主件和报告重核。报告摘要只引用已认证的证据，禁止以请求字段本身证明证据或通过。旧入口提交的无报告确认批准同样受约束。

把有效确认纳入既有复核有效性及发布提交重核。预检发现缺失或过期时返回受控原因，原子提交时按最新产物和证据再次判断。表格证据声明存在疑似项却无法验证时拒绝批准或发布。确认只允许通过该疑似项的人工复核条件，质量报告保留原判断，现有硬阻断及其他发布条件继续由其原 owner 负责。不存在有效疑似项的任务沿旧路径。审核发现真实错列时记录 `needs_fix`，用户可下载后在 Word 修正。正式发布仍要求平台登记并重新验收的有效主件。

优先在现有内部质量详情与复核 API 交付这项变化。质量详情返回确认所需的报告身份，复核受权用户可以通过同一 API 完成。工作台现有只读「复核位置提示」继续作为提示入口。本期不增加新的工作台审核界面。现有复核、报告和发布模型内部原子点继续适用，无数据库 DDL、独立确认状态表或额外发布通道。[复核领域](../../../app/domains/document_jobs/review.py) · [复核写入](../../../app/domains/document_jobs/use_cases/review_writer.py) · [发布领域](../../../app/domains/document_jobs/publication.py)

回退以保持已写入报告和审核记录可读、继续执行未确认阻断为前提。新报告已生成时，不回退到会忽略此规则或无法读取其证据的服务版本。样本本地位置及验证口径见 [回归输入](research/samples.md)。
