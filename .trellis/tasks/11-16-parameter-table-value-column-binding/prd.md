# 参数表数值列归属检查

## 目标

发现数据手册参数表中丢失的数值列归属。转换完成后仍提供原生可编辑 DOCX，审核人可根据质量报告对照源 PDF，在 Word 中核对或修正。疑似错列须经有权审核人确认对应产物和证据后，才可进入既有正式发布流程。

## 背景

本任务承接 [Datasheet 质量基线、表格与状态合同的 Q3 / AC4](../11-11-datasheet-quality-baseline-contracts/prd.md)，发布行为沿用 Q4 的产物与有效批准绑定。OPA228 第 7 页的电气特性表中，源 PDF 将两条 `VOS` 值分别置于 TYP 和 MAX，保存的 MinerU HTML 却跨越 MIN–TYP 和 MIN–MAX。SN74AC244 同一 PDF 的两份 v4 结果分别有 27 和 21 处合并，首轮额外 6 处为 MIN/MAX 数值跨列。[OPA228 问题记录](../11-11-datasheet-quality-baseline-contracts/issues.md#优先核查的-p0-内容问题) · [固定输入与预期](research/samples.md)

## 需求

| 编号 | 可观察行为 |
| --- | --- |
| R1 | 识别独立的 `MIN / TYP / MAX`、`LOW / NOM / HIGH`、`最小 / 典型 / 最大` 以及 SN74AC244 的 `MIN / MAX`。同组至少两个独立值列被非表头数值跨越时，记录 `table_semantics:value_column_span_ambiguous`。支持有独立分组标题的重复数值列。 |
| R2 | 保留已有合并和 Word 原生表格。报告逐项提供源 PDF 页、表、行、值和涉及的列，能区分同一页中相同数值及同名设备列。仅当可信来源几何能独立定位到具体列时，才可以报告 `table_semantics:value_column_binding_mismatch`。 |
| R3 | 疑似项仍可随可编辑内部 DOCX 交付。有权审核人须针对当前产物和当前报告明确确认列归属可接受。未确认、确认过期或审核认为需修正时，正式发布失败。若可信证据已证明列归属冲突，按既有质量阻断处理。 |
| R4 | 固定两份 SN74AC244 v4 ZIP 的原始字节身份、来源 PDF 指纹和独立预期以离线复现。OPA228 使用已有第 7 页 PDF 与对应保存包核对报告定位。 |

## 验收

- [x] **AC1 / R1、R4**。SN74AC244 首轮包的 5.2 表逐项报出两个器件组各三处 `V_IH` 异常，值为 2.1、3.15、3.85，合计六处。重传包通过本项规则，5.2 表中独立标注的 21 处合法合并保留。覆盖合法多级表头、跨列标题、空白跨列及三套表头别名。
- [x] **AC2 / R2、R4**。OPA228 第 7 页 6.7 节 `VOS` 的 `±5 µV` 与 `±100 µV` 分别定位到源行及 MIN–TYP、MIN–MAX 跨列。独立 PDF 标注用于人工验收，确认源 TYP 和 MAX。三份真实包按现有转换入口输出可打开的原生表格，实际 Word 网格保留输入 span。
- [x] **AC3 / R3**。错误包可下载内部 DOCX。普通批准、缺失或过期的确认均不能使疑似项获得正式发布资格。确认绑定的产物与报告都匹配后，才可通过本项发布条件。换件、重试或报告变化导致确认失效。发布校验拒绝发生时不创建正式发布记录。无疑似项样本沿用既有审核发布资格规则。

## 范围

本次交付覆盖表格语义检查、现有内部表格质量报告、既有复核与发布入口，以及三份输入的离线回放。自动拆列、推断每个数值的正确列、在线表格编辑、人工修正文件回传、历史批量重跑和生产变更均在范围之外。现有样本只提供表格级定位，单元格几何比对待有可信来源时另行落实。
