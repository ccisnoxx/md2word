# 降级页独占 Word 页

## 目标

让每个整页降级的源页在 Word 中独占一页：从新页开始，提示和页面图像在同一页，后续内容另起新页。来自 2026-11-02 重新审查的修复优先级第 3 项。

## 验收标准

- [x] 降级页前后的内容都不与它同页，连续降级页各占一页。
- [x] 首页或末页降级时不产生多余的空白页。
- [x] 提示与图片不分离；整页图像高度不会把提示或分节段落挤到下一页。
- [x] 降级页使用单栏和源页方向。
- [x] 没有新字段的历史 IR，计划和图片尺寸都不变，存档校验继续通过。
- [x] 用 LibreOffice 把 DOCX 转成 PDF，实测页数与内容归属。

## 范围外

新增 `degraded_page` 操作类型、取消模板页眉页脚、按源 PDF 尺寸设置页面（见 design.md）。
