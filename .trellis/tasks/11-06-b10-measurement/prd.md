# B10 定向测量

## 目标与授权

在固定合成本地 SQLite 数据集上测量任务列表、异常中心、文件保护查询和保留期清理计划四条读路径。只测量，不优化。用户已授权创建本任务文档，写完直接执行；不需要再次规划确认。

只新增本目录内的脚本、文档与结果；不改应用、测试、Spec、依赖、任务清单或本目录以外的状态文件。不 commit、push、发布，不连接 MySQL、生产、Provider 或 MinerU，不运行全仓或发布门禁。

- AC-2：描述增长趋势和成本来源，附实际代码行号。
- AC-3：提出预算并判断；未超预算建议结束，超预算只提最小后续方向，持久化索引接入 B08。
- AC-4：明确本地与 MySQL 的差异，MySQL 特有扫描、索引和并发行为标为需真实 MySQL 验证。
