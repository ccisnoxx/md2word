# Datasheet 质量基线、表格与状态合同

## 目标

让 Datasheet PDF 到 Word 的质量可以跨文档复现和比较。交付一套覆盖多份数据手册的 Golden Sample、可复算的质量基线、复杂表格的统一结构语义，以及从质量证据到正式交付的可审计合同。

## 背景

- [父任务](../10-12-datasheet-docx-delivery-quality/prd.md)已定义原生 Word 表格、技术 Token 完整、内部草稿与正式交付的权限边界。此子任务负责形成可执行的度量、结构和状态验收，父任务负责跨子任务集成。
- [P0 清单](../../../tests/fixtures/golden_samples/manifest.yaml)的四项均为 OPA228 切页。现有 [P1 英译中清单](../../../tests/fixtures/p1_translation_samples/manifest.yaml)也来自 OPA228。[组件样本策略](../../../docs/engineering/testing-acceptance-strategy.md#8-样本体系)记录了其他风险场景，最小 MinerU 夹具只证明组件行为。
- 当前分支已有 [Canonical Table Grid](../../../app/services/tables/models.py)、[质量与交付状态](../../../app/domains/document_jobs/delivery_state.py)、[追加式审核记录](../../../app/domains/document_jobs/review.py)和[发布快照](../../../app/domains/document_jobs/publication.py)。以当前实现、公开合同和可重放证据为基线，核对原实施清单的状态差异。

用户已确认七组指标和实施顺序，并授权将其提供的 TI SN54AC244/SN74AC244（SCAS514H）PDF 与 MinerU 结果用于验收。该样本按外部本地输入管理，另一个数据手册来源按既定准入规则补齐。

## 需求

| 编号 | 可交付结果 |
| --- | --- |
| Q1 | 版本化 Golden Sample 清单保留现有 OPA228 基线，引入至少两份不同的非 OPA228 源数据手册。新增样本合计覆盖多级合并表头、跨页逻辑表、技术符号密集内容，并包含至少一组有明确预期的质量阻断负例。正常样本覆盖 direct，另用至少一个非 OPA228 样本覆盖现有英译中路径。 |
| Q2 | 对每个适用样本输出转换成功、原生表格结构、技术 Token、页面视觉、人工修改、人工验收耗时、单文档成本和延迟的原始观测及汇总。记录输入、版本、环境、覆盖率、失败和缺测原因，支持按同口径比较。 |
| Q3 | 复杂表格在校验、渲染和验收证据中采用统一的行列、合并区域、表头与来源片段语义。跨页续表、重复表头、宽表以及缺片段都有可核对结果。保留原生 Word 表格可编辑性。 |
| Q4 | 明确执行结果、质量结论、审核决定、发布操作和交付投影的写入权、绑定身份、状态转移和不变量。历史审核与正式发布证据可追溯，发布版本及其绑定文件不可原地覆盖。 |

## 验收

- [ ] AC1 / Q1。提供两份或以上非 OPA228 源数据手册的合规来源、版本或页段、内容指纹和独立预期。正式 PDF、组件夹具、正常样本和阻断负例可区分。既有四项仍可按原口径对照，正常样本和负例分别汇总。
- [ ] AC2 / Q2。冻结一版指标口径。固定输入可重算自动指标，人工记录可绑定具体产物和审核轮次。每个比率报告分子、分母和覆盖，每项缺测带原因。超时、无效 DOCX、重复 Token、页面未匹配、未采集工时和无账单分别有可验证的处理结果。
- [ ] AC3 / Q2。输出一次版本化基线报告，按转换模式和运行证据层级分组。基线能区分已有硬要求与待实测校准的阈值。既有 P0 目标沿用清单，标注的受保护技术 Token 完整率目标为 100%。
- [ ] AC4 / Q3。用独立标注分别核对网格和实际 OOXML。至少覆盖横纵合并、多级或重复表头、跨页续表、宽表和缺片段。缺片段报告定位与质量状态，并按现有规则阻断发布。合格样本保留单元格结构、可编辑性和技术内容归属。
- [ ] AC5 / Q4。定向验证草稿下载、有效批准、发布前核验、证据失效和发布后保护。覆盖重试或换件、历史未绑定批准、相同请求重放、冲突请求及提交时证据变化。发布失败后无半提交，发布成功后可回查固定产物和证据。
- [ ] AC6 / Q3、Q4。记录与现有 TAB、QA、REL 合同及验收的对应关系，列出实际修复、复用和待验证项。需要真实环境或人工签字的验收证据单独记录取得情况。

## 范围

范围限于 Datasheet PDF 到 Word 的样本与质量度量、复杂表格路径和现有审核发布合同的收敛。完整语言矩阵、在线编辑、人工 Word 回传、新发布分发功能、历史数据批量迁移以及生产策略调整属于独立任务。规划审阅通过后进入实施，真实服务调用、付费验证和生产操作遵循各自授权边界。
