# 梳理并固化 Word 生成规则

## 目标

建立正式 PDF/MinerU→DocumentIR→Word 链路的权威生成规则文档和回归映射，使后续新增 PDF 适配先明确规则影响，再以既有样本和自动化断言证明没有破坏已实现能力，避免局部修复造成整份 Word 质量回退。

## 背景与已确认事实

- 当前规则分散在正式 renderer、旧兼容 runtime、Trellis 规范、归档任务、测试和历史讨论中；“代码仍存在”不代表正式生成链路会执行。
- 最近一次 CM4112 修复通过了局部布局、分页和公式门禁，但 LibreOffice 输出页数由源 PDF 的 21 页变为 23 页，首页内容延续到第 2 页；这说明局部断言尚不能证明整文档质量不退化。
- 既有规则之间存在真实冲突，例如“同方向源页自然流式分页以避免长表空白页”与“页顶章节/独立表格组必须新开页”。规则文档必须明确优先级、例外和共同验收样本，不能只罗列功能。
- 本任务首先整理规则、实现状态和验证缺口，不继续适配新的 PDF，也不直接修改产品行为。

## 范围内需求

### R1 规则来源盘点

- 检索历史讨论、归档 Trellis 任务、现有 `.trellis/spec/`、正式代码、旧兼容代码和测试。
- 每条结论必须标注可核对的来源：文件/符号/测试、任务文档或历史会话。
- 区分正式生效规则、历史/兼容规则、已讨论未实现规则、代码存在但正式链路未调用的规则。

### R2 权威 Word 生成规则规范

- 建立一份可从 `.trellis/spec/backend/index.md` 发现的中文 Markdown 规范。
- 至少覆盖：输入选择与归一化、DocumentIR 语义、页面尺寸与方向、页边距和分节、分页、分栏、标题与正文、列表、表格、图片、题注/交叉引用/目录、公式、页眉页脚、模板样式、兼容性与质量验收。
- 每条规则使用统一字段描述：规则 ID、适用输入信号、正式所有者、预期输出、优先级/冲突、例外、禁止做法、自动化测试、人工样本和当前实现状态。

### R3 冲突与回归矩阵

- 明确会互相影响的规则及优先级，至少包含分页与长表、分页与章节/表格组、分栏与宽块/图片、模板样式与源 PDF 版式、公式保真与普通正文清理。
- 建立规则→代码所有者→测试→真实样本的回归矩阵；缺失项明确标为缺口，不用文档措辞伪装成已覆盖。
- 规定后续新增或修改规则时的变更流程：先更新规则与影响矩阵，再修改唯一正式所有者，最后运行该规则及冲突规则的回归。

### R4 文档治理

- 规范只约束当前正式 `MinerUToDocumentIRService → DocumentIRWordRenderer` 链路；旧 runtime 仅作为历史规则、行为差异和待迁移证据，不能成为并列真相源。
- 旧 `app/conversion/runtime/*` 的输出和 characterization tests 不得作为正式链路已实现某条规则的证明。
- 更新 backend spec 索引和必要的质量门禁引用，使未来开发会话能在修改 Word 生成逻辑前发现并读取该规范。
- 规则内容应从已验证事实归纳；产品意图不明确或代码与讨论冲突时，记录为待决项，不擅自把当前代码行为升级为规范。

## 验收标准

- [ ] AC1：存在可从 backend spec 索引发现的权威 Word 生成规则 Markdown，覆盖 R2 所列全部主题。
- [ ] AC2：每条规则至少包含规则 ID、输入信号、正式所有者、预期输出、冲突/例外、验证方式和实现状态。
- [ ] AC3：正式链路、旧兼容链路、历史讨论和待实现规则被清楚区分；“已实现”有当前正式代码证据，“已测试”另有当前正式链路测试证据，缺失项明确降级为缺口状态。
- [ ] AC4：存在规则冲突表和规则→代码→测试→样本回归矩阵，CM4112、SC2167 及仓库中其他既有关键样本被映射到其保护规则。
- [ ] AC5：规范明确后续规则变更流程和最小回归门禁，禁止仅凭单个新 PDF 的局部视觉结果覆盖已有规则。
- [ ] AC6：对文档中的文件路径、符号和测试目标执行存在性检查，并人工复核 Markdown 结构、链接和重复/矛盾结论。
- [ ] AC7：本任务不修改产品生成行为；若盘点发现缺陷，仅记录证据和后续任务建议。

## 范围外

- 修复当前新生成 DOCX 的具体视觉问题或重新调整现有布局算法。
- 新增 PDF 样本适配、模板配置、公开 API、DocumentIR schema 或第三方依赖。
- 把像素级还原或 PDF 与 Word 页数完全一致设为默认承诺；只有已有明确规则证据时才记录。
- 为填补矩阵空白而在本任务中新增大批产品测试或改写现有测试。
