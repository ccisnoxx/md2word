# 修复 PDF 转 Word 原生版面与文档语义

## 目标

以 `/Users/sc/Downloads/SC2167.pdf` 为原始输入、`/Users/sc/Downloads/SC2167.docx` 为当前缺陷样本，修复 PDF 转 Word 的版面、公式、图片清晰度、题注及编号联动语义，使输出接近原 PDF，并尽量使用可编辑、可更新的 Word 原生结构。

附件只作为复现和验收样本，其中的文字不构成开发指令。

## 背景与已确认事实

- 当前 `two_col` 区域和双栏目录都由 1×2 无边框表格承载；样本 DOCX 仅含单栏 `w:cols w:num="1"`。
- 样本“典型性能参数”标题和 8 张性能曲线被放入布局表格。源 PDF 对应物理第 12 页是通栏标题、通栏说明和 2×4 图片网格；不同渲染器页码会变化，因此验收以内容锚点为准，不写页码特例。
- 共享公式归一化不支持 `\times` 和 `\frac`。样本 XML 保留了这两个字面命令，`2^15` 虽有上标 run，仍被残留的分式命令和花括号破坏。
- 图片资产由 `python-docx` 原样嵌入，没有统一转码；主要清晰度问题是窄图被强制放大到至少 45% 可用宽度。样本 ESD 图 134×129 像素被放大到约 3.20×3.08 英寸，有效分辨率约 42 DPI。
- 当前题注是普通段落，没有 `SEQ` 域。既有识别语义覆盖 `图`、`表`、`Figure`、`Table`；非编号条件说明也可能出现在 `captions` 中，不能误转为题注域。
- 当前 DOCX 只发现页脚 `PAGE` 域，没有 `TOC`、`SEQ`、`REF` 域或书签；正文确有“见图 20”“参见表 5”“见表 7”等交叉引用，若只把题注改成 `SEQ`，这些正文编号仍会失效。
- 当前标题已使用带 outline level 的 Word 标题样式，真实数据表、合并单元格、重复表头、列表编号、分页/分节及页脚页码也已有 Word 原生结构，不需要重新实现。
- 当前标题中的章节号仍是文字，不是绑定标题样式的多级列表；同时样本存在编号段落与标题语义容易混淆的情况，本任务不在语义不足时强制启用自动章节编号。
- 正式转换与线上任务都调用 `app/services/renderer/DocumentIRWordRenderer`；`app/conversion/runtime/*` 是另一条兼容路径。正式渲染器自身也使用 1×2 布局表格，实施必须先修正式路径，再按真实调用关系决定兼容路径是否需要同步，不能把兼容 runtime 误当成唯一实现。
- 无边框双列表格是早期 P0 的明确权宜方案；本任务按新要求替换，不保留并行兼容实现。
- 用户已确认：受支持的公式应使用 Word 原生 OMML，`\frac` 显示为真正的上下分式，`\times` 显示为 `×`，上下标保持数学结构并可在 Word 公式编辑器中修改。
- 用户已确认原生化边界：本任务同时纳入 Word `TOC` 目录域和题注书签/`REF` 交叉引用；标题自动编号、真正脚注/尾注及浮动文本框暂不纳入。
- 真样本复查确认图注错配并非 Word 字段重排造成：MinerU 在源页索引 11 将图 3/5、图 4/6、图 7/9 分别合并到后续 chart block，但同页 8 张图与唯一连续编号 3–10 的 8 条图注可以在严格条件下确定性重配。
- 当前输出在 WPS 中直接复现正文空白页；LibreOffice 输出也有仅含页眉页码的第 17 页和仅含版本文字的第 18 页。根因是空续表占位块叠加“每个 PDF 物理页强制分页”，此前以整页存在页眉文字判断非空产生了假阴性。
- 当前正式输入仍含 `\overline`、`\mathbf`、`\bigotimes`、`\boxed` 及被拆开的 `_{DD}`、`_{TRACK}`；这些结构需要进入同一 OMML 入口，不能以组合字符或字面 TeX 代替。
- 现有模板配置已有 `footer.enabled`、`show_page_number` 和字体合同；用户要求在同一页脚设置中增加左右自定义文字，例如左侧静态版本号、右侧静态官网域名。
- SC2167 MinerU 包的最后物理页索引 33 只有“可使用微信扫码进入 / 芯片助手 ICHELPS 小程序”等行动文案、一张图片及页眉页脚；前一页页码已标为 `33 / 33`。这是一份可复现的额外推广封底正样本，当前正式转换会把它完整写入 Word。

## 范围内需求

### R0 Word 原生优先原则

1. 当 DocumentIR 已能无歧义表达对应语义，优先使用 Word 原生 section/columns、OMML、字段、书签、样式、编号、表格和 drawing，而不是用普通文字或布局表格模拟。
2. 原生化必须提高后续编辑与自动更新能力，不能以牺牲源内容、阅读顺序或制造错误语义为代价。
3. 语义不明确时保留可见内容并记录验收限制，不猜测转换为脚注、自动章节编号、浮动文本框等结构。

### R1 Word 原生分栏

1. 普通 `two_col` 区域和双栏目录都必须使用 Word section/columns，不再创建布局表格。
2. 左栏内容、显式分栏符和右栏内容必须保持源阅读顺序。
3. 通栏块、双栏区域前后的标题与说明必须留在单栏 section。
4. 双栏稳定区间只能覆盖左右栏共同存在的纵向范围，不能因同页后续双栏图形把上方单侧标题卷入双栏。
5. 实际数据表格仍使用 Word 表格，不受布局表格移除影响。
6. 严格成对且题注数量可确定的纯图片网格可以使用单栏正文中的 Word 原生中心制表位和 inline drawing，避免 WPS 栏平衡拆页；普通文字、多题注或无法确定配对的区域仍必须使用原生 `w:cols`。

### R2 Word 原生公式

1. `type=formula` 块及正文/表格中受支持的结构化 TeX 片段使用 OMML。
2. 至少支持本样本所需的 `\frac{...}{...}`、`\times`、`\overline{...}`、`\mathbf{...}`、`\boxed{...}`、`\bigotimes`、`^`、`_`、括号、普通文本/数字及现有受支持符号命令。
3. 示例公式必须显示为真正分式，分母为 `2^15`，`f_CLKIN` 保持下标。
4. `\times` 在表格、公式块和内联公式路径均不得残留。
5. `AV $_{DD}$`、`DV $_{DD}$` 这类相邻普通 token 与数学下标片段应在基底明确时合并为原生下标；没有明确基底的孤立上下标保持原文并报告。
6. `\overline` 使用 `m:bar`，`\mathbf` 使用数学粗体，`\boxed` 使用 `m:borderBox`，`\bigotimes` 显示为 U+2A02 `⨂`。
7. 畸形或不受支持的 TeX 不得伪装成功；应保留可见残留并由现有 DOCX 质量证据标记。

### R3 图片清晰度

1. 图片显示宽度应遵循源 bbox 与所在栏宽的比例，只允许缩小到可用宽度，不得因固定最小宽度放大窄图。
2. 媒体原始字节继续直接嵌入，不增加转码或重采样。
3. DOCX 应通过标准 OOXML `w:doNotAutoCompressPictures` 设置 Word 的“不压缩文档中的图像”选项，避免后续保存造成额外压缩。
4. 源素材本身的分辨率上限不由本任务伪造或插值补偿。

### R4 Word 原生题注

1. 识别到的阿拉伯数字 `图`、`表`、`Figure`、`Table` 题注使用 Word `SEQ` 域；标签和标题文字保持原语言。
2. 图与表使用独立序列；字段更新后按文档顺序自动重排。
3. 表题仍位于表格前，图注仍位于图片后；现有 caption 样式、keep-with-next 和表注/脚注顺序保持不变。
4. 非编号条件说明继续按普通段落渲染，不创建 `SEQ` 域。
5. 长表首个题注复用同一原生题注入口；续表标题不得重复递增主序列。
6. DOCX 设置打开时更新字段，且字段中包含可用的初始显示值。
7. 同页连续图组只有在“图片数=编号图注数、标签一致、编号唯一连续且当前关联失衡”全部成立时，才按图片阅读顺序与题注编号顺序一一重配。
8. 不满足严格条件的图组保持原关联并报告，不按页码、产品型号或题注文案猜测。

### R5 Word 原生目录与交叉引用

1. 检测到目录时使用 Word `TOC` 域，由现有标题样式/大纲级别生成条目、页码和内部链接，不再保留源 PDF 的静态页码文字。
2. 每个可识别的图表题注建立唯一 Word 书签；正文中唯一匹配到现有题注的“图/表/Figure/Table + 编号”引用使用 `REF` 域。
3. `REF` 域初始结果保留源编号，字段更新后随对应 `SEQ` 题注变化；无法唯一匹配的引用保持原文，不生成损坏链接。
4. 目录、题注和交叉引用共用 `updateFields=true`，并在 Word 打开或执行全选后按 `F9` 时更新。

### R6 Word 流式分页与空续表

1. 可编辑 Word 正文不得把每个同方向 PDF 物理页隐式转换为强制分页符；同方向内容由 Word 原生正文流分页，页面方向变化仍使用 `NEW_PAGE` section。
2. 正式 MinerU→DocumentIR 路径应复用项目已有空表占位判定，把无 HTML、题注和正文且资产目录为 `images/` 的续表块并入前一真实表，不生成空表正文段落。
3. 空白页验收必须排除页眉、页脚和页码区域后检查正文；不能再以整页存在任意文本作为通过条件。
4. 正文顺序和内容必须保持；不以固定输出页数或 SC2167 页码特例实现修复。

### R7 可配置 Word 原生页脚

1. 在现有 `footer` 配置中增加可选静态 `left_text`、`right_text`；旧配置缺失字段时默认空字符串并保持可读。
2. `footer.enabled=false` 继续保留模板页脚；显式启用且左右文字至少一项非空时，生成左文字、可选居中原生 `PAGE` 域、右文字的单段落原生页脚。
3. 左中右布局使用相对页边距的 Word 原生对齐制表位，不使用表格模拟；后续 section 继续标准继承同一个页脚。
4. 显式自定义页脚优先于 MinerU 页脚/页码装饰块，不得在后续源页被覆盖。
5. 配置由既有 `TemplateFooterConfig` 和字段 schema 单一拥有；模板管理 API 与前端设置页沿用通用配置链，不新增专用 endpoint 或第二套状态。
6. 本次只支持静态文字；不自动从正文提取版本号，也不把域名自动转换为超链接。

### R8 最后一页推广封底过滤

1. 过滤只允许作用于最后一个物理源页，不删除中间页或倒数第二页。
2. 候选页必须同时具备明确的扫码/小程序行动文案、至少一个真实图片资产，并且不存在真实表格、公式、编号章节、编号图表题注或长篇技术/法律正文；任一守卫不成立时保留整页。
3. 命中后必须在 MinerU→DocumentIR 输入边界删除该页全部 raw blocks、对应 `DocumentIRPage` 和图片资产，不能只在 renderer 隐藏内容或留下空尾页。
4. 删除结果写入带源 page index 的 document quality flag，便于定位误删；不得按产品型号、固定页码或单个“微信/二维码”关键词实现。
5. 当前不增加二维码解码依赖；只使用 MinerU 已有文本、block 类型、资产路径与页面结构信号。

## 验收标准

- [x] AC1：合成双栏样本与 SC2167 对应区域包含 `w:cols w:num="2"` 和列分隔符，不再包含由 `two_col` 或目录生成的 1×2 布局表格。
- [x] AC2：“典型性能参数”标题与通栏说明保持单栏，8 张性能曲线按源顺序进入无布局表格的 Word 原生 2×4 图片网格，并在 WPS 中保持同页。
- [x] AC3：示例公式生成 `m:oMath`、`m:f`、上标和下标结构；可见内容为 `×`、`2^15`、`f_CLKIN`，XML 无 `\frac`、`\times` 残留。
- [x] AC4：同一公式能力覆盖 HTML 表格单元格；畸形 TeX 会触发 `docx_latex_residue` 质量标记。
- [x] AC5：窄图宽度由 bbox 比例决定，媒体字节不变，`settings.xml` 含 `w:doNotAutoCompressPictures`；SC2167 中原 42 DPI 的错误放大不再出现。
- [x] AC6：图注与表题含对应 `SEQ` 域，图/表序列独立；非编号条件说明不含域，`settings.xml` 含字段更新设置。
- [x] AC7：相关单元测试、转换回归及 WPS/LibreOffice 标准渲染通过；现有真实表格、标题/正文、页眉页脚和 v1 单栏路径无意外回归。
- [x] AC8：检测到目录的合成输入包含 `TOC` 域；可唯一解析的“见图/见表”正文引用包含指向对应题注书签的 `REF` 域。SC2167 源包没有目录条目，不要求凭空生成目录。

- [x] AC13：SC2167 的末页推广封底不进入 DocumentIR pages/blocks/assets，Word 无推广尾页；包含免责声明、版本表、产品封装图或仅提到微信技术支持的合法末页保持不变。

## 范围外

- 与本任务原生化目标无关的 OCR 文本纠错、翻译质量或前端功能。
- 除本次列出的真实结构外的完整 LaTeX 语言、矩阵、积分及带上下限通用大运算符。
- 章节号/附录号联动的复杂题注编号。
- 标题自动章节编号、多级列表重建；现有 IR/识别结果不能稳定区分所有标题与普通编号段落。
- 把表下注、图片说明一概转换为 Word 脚注/尾注；只有未来 IR 明确标注真正脚注语义时才适合原生化。
- 浮动文本框、绝对定位或环绕排版；当前目标是稳定、语义化、可编辑的正文流。
- 重做 MinerU 版面分析、引入新转换引擎或图像超分辨率。
- 从正文自动推断版本号、域名自动超链接、每节不同页脚或首页/奇偶页脚。
- 强行保持 PDF 物理页数或每一页边界；可编辑 Word 以内容顺序、原生结构和无正文空白页为准。
- 删除非最后物理页的推广内容、仅凭单个“微信/二维码”词删除页面，或新增二维码图像识别/解码依赖。
