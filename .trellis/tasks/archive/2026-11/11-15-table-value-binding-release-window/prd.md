## 范围与授权

- 沿用 `claude/parameter-column-binding-check-cb3979`。本轮仅建任务和交付计划。
- 后续分别经授权执行生产候选上线、单公司开启和需要现场执行的回滚。只复用已维护的生产入口、配置和存储合同。
- 本阶段以单公司为上线范围。代码改动、MinerU 升级、全量扩围、放宽逐页核对及解除已知样本阻断均不在范围内。

## 验收标准

| 门禁 | 必须取得的证据 |
| --- | --- |
| 关闸候选运行 | 实际 API/消费者和恢复执行者的镜像身份一致。总开关关闭、白名单为空，五个 Poppler 可用且同版本。目标账号完成真实验签回调，当前代 Worker 归档并产出可重读 Word。新任务没有自动数值列修正或 blocker 解除，管理员新同包接纳按关闭合同拒绝。 |
| 单公司灰度 | 所有执行者的总开关和唯一 `(tenant_id, company_id)` 一致，名单内外或关闭态对照可对账。名单内真实回调产生已认证的同源及 Word 正例，证明来源到实际格的完整链路。仍有未决的生成件不能批准、发布。 |
| 关闸与回退 | 停用后新任务不进入自动核定，新同包接纳拒绝，已接纳 UUID 可对账。在途代及已持久化证明仍可由兼容版本读取和处理。回退镜像、编排、队列与对象生命周期的兼容性有明确记录。 |

真实回调缺证、有效配置不一致、来源不可信、错列、越出名单或未决放行均暂停升档。第六阶段的验收结论分别记载关闸生产结果、单公司结果及回滚证据。
