# D2 实现代价核实与替代方案（2026-11-02）

## 核实结论

已确认的 D2（降级页的块保留在 IR、渲染时整页替换）需要修改的证据/校验 owner：

| owner | 现有期望来源 | 需要的改动 |
|---|---|---|
| `renderer/evidence.py` 完整性计数 | IR 全部正文块的图片/表格/标题数量 | 排除降级页，加上整页图像 |
| 公式报告（`formula_source_inventory`） | IR 全部公式来源 | 排除降级页 |
| 图片版式报告（`verify_image_report`） | IR 全部图片块的计划 span | 排除降级页 |
| 表格证据 / 逻辑表格计划 | 全部表格单元 | 排除降级页 |
| 块渲染证据与锚点 | 每个块有处置 | 降级块处置 `superseded` |
| 内容契约范围 | 块级 scope | 排除降级页 |
| 来源对账（`build_source_integrity`） | 图片块须有资产 | 降级页失败图片豁免 |

7 个以上证据模块需要“排除降级页”的平行改动，回归面大。

## 替代方案 D2'（IR 层替换）

converter 在构建 IR 时，把降级页的源块替换为两个合成块：一段提示文字 + 一个整页图像块（资产为整页栅格 PNG）。

- 渲染器与全部渲染证据无需改动：合成块就是普通段落与普通图片。
- 只需改来源对账：降级页的源块记录在 `metadata.degraded_pages`（含源 JSON 指针与原始片段哈希，可追溯），对账期望值扣除这些源块；合成块标记为非源块，不计入主块。
- 质量：降级原因 issue 以非中止 blocker 保留在验证报告中，`base_quality` 自动得到 `blocked`；无需新增质量 flag。
- 代价：降级页的文字不进入 IR，因此该页不参与复核提示与翻译（反正已是图像）；提示段落按普通段落处理（翻译模式下会被翻译）。

## C1 范围补充

验证器在 `validate()` 阶段遇到的块结构错误（如块载荷非法）会在归一化前立即中止，这类块无法可靠构造 IR。C1 先只覆盖 `complete_validation` 及之后才成为致命的错误：无法解析的表格 HTML、P0-4 回退失败的图片；块结构错误保持整体失败，留给后续子任务。
