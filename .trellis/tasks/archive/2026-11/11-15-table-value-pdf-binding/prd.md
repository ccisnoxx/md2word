# 参数值列的 PDF 坐标匹配

## 目标

用同源 PDF 的可见文字及位置核定疑似跨列的参数值。在证据能确定唯一行列时复用现有 Grid 修正，存疑项继续阻断并交人工核对。

## 当前基础

第二阶段已支持来源绑定的人工核定及实际 Word 认证，完整 `gs-008` 原报告有 23 处跨列发现。[第二阶段验收](../11-15-table-value-column-review/validation.md)

本轮只读探查从完整缓存的原件定位到两处值，在 PDF 中分别得到 `±5 µV → TYP`、`±100 µV → MAX`。表头色块、数据行的分段横线、独立行锚和可见字形均已观测。[实测记录](research/gs-008-geometry.md)

## 需求

- R1 在本地正式原排版转换中显式开启。只使用可信配对的源 PDF 与保留的 MinerU 结果，不从名称、文档文字或相同页尺寸推断同源。
- R2 从第一阶段已经报告的跨列 blocker 取候选。只有唯一表、独立的行证据、完整可见数值、独立数值列及一致单位都成立，才生成自动核定。
- R3 自动核定走第二阶段的来源校验、Grid 修正和实际 Word 认证。保留源 Grid 与原 findings，只解除已认证的对应条目；自动核定可追溯至 PDF 位置证据。
- R4 有歧义或证据不可用时保留 blocker，给出源表、格位和原因供人工核定。显式人工记录沿用既有校验，已核定的格位由人工记录控制。
- R5 用同一套列归属规则处理不同的参数名、数值、列标签和受支持的表格版式。从本次源表的标签、行锚和 PDF 几何推导目标列。样本的指纹、格位和期望列仅用于回归。

## 验收

- [x] AC1（R1、R2、R3）不传入第二阶段人工样表，以完整 `gs-008` 同源包两次回放，分别从 PDF 证据推得 `±5 µV` 的 TYP、`±100 µV` 的 MAX。核对实际 Word 两处均只占一列、释放格为空、`±75` 及单位合并正确。两次证据与表格结构一致。
- [x] AC2（R1、R2、R4）同名同文本但 SHA 不同、缺可信配对、扫描件或不可见文本、重复值、行上下文冲突、跨列边界或单位冲突均不产生相应自动核定。其原 blocker 保留，能定位到人需核查的源格。
- [x] AC3（R3）完整样本保留原 23 项，解除集合恰好等于实际 Word 认证的修正集合。其余候选逐格核验，剩余数量以实测为准。改变或移除自动出处、混用旧实物、错放 Word 值，均不能取得修正认证。
- [x] AC4（R3、R4）同源有效人工记录可与自动处理共用，其格位不会被自动结果覆盖。过期人工记录仍整批拒绝。关闭自动入口时沿用原本地转换与人工记录回放。
- [x] AC5（R2、R3、R5）独立构造普通划线表 PDF 和具有跨列错误的 MinerU 表。用不同的参数及数值，验证非右对齐的科学计数值归 HIGH、另一值归 LOW。经本地入口和实际 Word 重读认证，两列各自落位，压在列界的值保持 blocker。
