# PDF 参数值列绑定方案

## 本地入口与来源配对

建议在现有正式转换入口添加显式选项 `--auto-table-value-columns`，结合 `--source-pdf` 和保留的 MinerU 结果包。已选择的内容列表、同文档 layout、原件及 Grid 都从当前转换获得，观察应在归组和来源账本完成后、数值列修正接纳前执行。

首版从受信的已保留原始结果包找与实际选定的 content list 同根、同文档的唯一 `*_origin.pdf`，核对它和本次源 PDF 的实际 SHA-256。已有可信样本清单时也可核对预先记录的 PDF 和内容列表成对指纹。缺少或冲突的配对证据时不取自动结论。完整 `gs-008` 使用包内原件，仓库同名 PDF 是配对拒绝用例。[来源与坐标调研](research/pdf-observation-and-coordinates.md)

页坐标仍由 `layout_signals.pdf_point_bbox` 转为左上原点的 PDF 点。用 `read_same_document_layout` 核对唯一同文档 layout 的页号、页宽高与摘要，并和源 PDF 实际页框、文字及绘制坐标一致性对账。首版支持无旋转、同一 MediaBox/CropBox 且能确认尺度的页。一个页只读取一次，给该页的所有候选复用。超时、异常几何或不完整的输出按未决处理。

## 读什么证据

复用本地基线工具已用的 Poppler `pdftotext -bbox-layout` 词框读法，局部读取坐标与词序。用同一 Poppler 的 `pdftocairo -svg` 读取轴向色块、直线、有限平移、轴向反射及可见字形位置，相关裁剪须包含证据位置。用 `pdftohtml` 交叉核对同页的可见字面，识别 PDF 的 `ActualText` 以相同的字形位置和数量提供不同数值的情形。取证工具版本需要一致。预览 `page_observer` 的公开结果只保留字形框，当前 Python 环境也缺少其可选的 `pdfminer`。

| 条件 | 取证与决定 |
| --- | --- |
| 唯一表及表头 | 源表 bbox 内只接纳一组与源 Grid 列标签次序一致的表头。独立列由贯穿表头和候选行的竖线及封闭行带确定，也可由实际表头色块与数据行分段横线共同核实。后一种形状至少一条相邻行线须独立印证列分界，且另一条一致。数据区已有对应内竖线而该行断开的情况保留为未决。 |
| 唯一数据行 | PDF 行带来自实际横线。先用独立于疑似值的已知同行格、条件或纵向合并组定位行。文本重复时须有独立的可核对组范围约束。源行号可核对顺序，单凭行号不成立。 |
| 可见完整值 | 精确匹配完整数值 token，保留正负、比较符、指数及单位含义。首版仅做明确的符号等价、空白和简单已确认下标投影，复杂表达式交人工。词框内核对实际渲染字形的位置，同一区域的多个可用词框或不可见文本均未决。 |
| 唯一数值列与单位 | 值词框整体落在一个已证实的独立列，列目标属于原跨度，且释放格没有其他词或未匹配字形。使用色块和横线时，同时核对值与该列标题实际右沿的对齐。由连贯竖线闭合的格位可容纳不同对齐方式。共享单位按真实纵向合并区域和原 Grid 的 rowspan 归属确认。 |

边界端点、所需右沿对齐的容差为 0.5 pt，值词框须与列界和行界各保持至少 0.5 pt 的距离。同文档 layout 与 MinerU 点框限定表区域。用贴边、重复和共享值负例核对阈值，并用独立 LOW/HIGH 划线表验证迁移到另一种版式、列标签和数据。

## 完整 gs-008 归属

表区域来自 `/0/2`。数据行内侧的两个数值列分隔处没有贯穿竖线。证据来自物理表头色块、至少一条吻合列界的行线分段和同列的实际文字右沿。

- 源行 2 的 `±75` 锁定第一条数据行，表外条件段的另一个 `±5` 被区域排除。行内 `±5` 的词框完全落在 TYP 的列带。
- 源行 3 用同一 `U, P grades` 纵向组和 `T_A = −40°C to +85°C` 条件锁定。此行的 `±100` 落在 MAX 的列带。PDF 的 A 为下标，匹配时按已确认的符号关系核对。单位 `µV` 为两行共用的纵向单元格。

## 复用修正流程

1. 以 `iter_parameter_value_column_spans` 的源 finding 作为候选。先校验显式人工记录，跳过人工已经占用的原格。自动结果按片段与人工核定合并，沿用现有 `resolve_table_value_column_review` 与整批接纳。一个词框、源格或目标存在竞争时保留相关 blocker。显式人工记录过期时仍按原合同拒绝整批。
2. 自动生成的逐格核定附可选的内部 `pdf_binding`。保存取证版本、layout 摘要、页与表/行锚、列标题与边界、完整数值 bbox 和实际字形位置等能复核的最小证据。复用父记录的 PDF、原表、原单元格和旧跨度绑定。几何出处参与核定指纹。人工 JSON 保持原入口，不能提交自动出处来充当观察事实。
3. 使用第二阶段的同一个渲染计划和 Word 实物认证。实际写入、空槽与内容吻合后，在交付证据记录自动修正的出处指纹。冻结 IR 与 Word 重读重建认证，再次本地转换从实际源 PDF 重新取证。
4. 在既有输出 IR 中保存未决项的原 finding ID 与固定原因，CLI 汇总未决数和源定位。人可据此走第二阶段的人工记录。未决项不生成 correction，原 blocker 不变。无自动选项的历史 IR、核定记录和报告省略新字段。
