# 线上正式转换接入参数值列绑定

## 目标

线上原排版转换可在同源证据确定时修复参数值的列归属。由实际 Word 确认修正，业务人员可定位仍有疑义的源格，管理员可在同包上提交人工核定并生成新一代。审批与发布消费当前代的有效质量。

## 基线与范围

- 沿用 `claude/parameter-column-binding-check-cb3979`。第三阶段本地实现为 `2669e9b0`，已经用完整 MIN/TYP/MAX 实物和独立 LOW/HIGH 划线表证明两种版式。[第三阶段验收](../11-15-table-value-pdf-binding/validation.md)
- 首版适用 `direct` 原排版，以默认关闭的开关接入正式 Worker。人工核定由内部 Admin 复用现有新代操作的权限与代次事务，逐格定位沿现有复核读取。
- 本轮交付实现与本地隔离验收。部署、生产启用与真实回包抽验另行安排。翻译模式的列修正、普通用户编辑表格、字体独立识别和合法真共享格的人工放行规则留作后续范围。

## 需求

- **R1 同源资格**。核对任务绑定的 PDF 和明确登记的 MinerU 结果文件、实际字节及解析血缘。复用第三阶段对选中 v2、包内原件摘要、同文档布局及页框的核验。来源未获证或 PDF 证据不足时保留可定位的原跨列 blocker，正式输入损坏沿既有错误合同关闭。
- **R2 实物与交付**。线上走同一 Grid 修正、Word 输出及持久化重读。原报告保留全部原发现。有效 flags 仅解除实物认证对应的 ID，其他风险仍进入基础质量；现有批准与发布拒绝继续生效。对本阶段已应用修正的结果，批准时也要求绑定的实物证据可重验。
- **R3 人工核定**。在现有授权质量读取中提供当前代、片段、原 finding、源页与表框、零基行格及原因。有效人工记录以冻结的同源 PDF、ZIP 和原格为依据，整批接纳，生成当前任务的新一代，复用原包及已有有效人工项。越权、旧代、换源或任一格不匹配时整批拒绝。
- **R4 执行兼容**。方案兼容历史 IR、报告、正在恢复及已发布的结果。新接入的可选取证有文档总预算。渲染降级保留可追溯的源 IR 和整页质量 blocker。开关只影响新取证与请求接纳，已冻结的同代恢复按原证据读回。

## 验收

| 验收 | 可观察结果 |
| --- | --- |
| A1（R1、R2） | 完整 `gs-008` 同源包从文件上传与 MinerU 登记进入正式 Worker，Word 的 `±5 µV` 只归 TYP、`±100 µV` 只归 MAX，相邻 `±75`、释放格及单位合并正确。原 23 条仍可查。对固定取证版本核对已认证解除集合和剩余 14 条阻断。 |
| A2（R1、R2） | 独立 LOW/HIGH 实物划线表中，`7.2e-4 s` 归 HIGH、`43 ms` 归 LOW、贴列界的值仍阻断。再用有真实清晰依据的完全核定用例通过普通审批和发布先决条件，证明可放行路径。 |
| A3（R1、R2、R4） | 同名同文字异源、缺原件或唯一布局、字形与行列歧义、工具缺失或预算耗尽时，保留原 blocker 与原因。跨任务、ZIP 实物摘要变化与实际 Word 错列触发正式完整性失败。篡改或丢失绑定报告的修正结果不能批准或发布。 |
| A4（R2、R3） | 管理员能定位当前未决项并提交同源整批记录，同包新代完成后从实际 Word 复核精确落位。重复请求幂等，逻辑上只接纳一代。旧代、任一条过期、伪造自动出处、重复冲突、无权限、归档过期或并发竞争落败时无部分修正。 |
| A5（R2、R3、R4） | 剩余 blocker 的当前结果仅可按授权查阅内部草稿。审批和发布分别返回既有阻断。关闭开关、历史读回、同代恢复、明确旧解析包重用、整页降级和迟到写者均按各自当前代合同处理。 |
