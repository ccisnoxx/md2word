# 设计

- 表格质量模块集中定义 `REVIEWABLE_VALUE_COLUMN_RULES`，涵盖 v2/v3 跨列规则及可重放的 v1 跨列规则。旧共享限值提示使用独立规则 ID，不属于这组候选。新 v3 默认策略将跨列疑点设为 warning。finding ID 原本就独立于严重度。
- 自动取证的候选、人工核定的可用原 finding、修正证据与最终未决定位均按规则 ID 关联。未决还须命中最终活动 flag，且同一片段、源行与源格一致。已修正项仍使用实际 Word 格位、证据指纹和原范围校验。
- 在现有表格详情的活动数值列及其未决定位投影 `manual_review_required`。警告仍由活动 flags 表示。沿用现有审批、下载和发布状态机，审批确认绑定当前主件和报告，发布继续检查其他质量、权限和工件条件。
- 同源不足或 PDF 观测不可用时，宽表夹具的 `layout_wide_table` 仍留在诊断中。在基础质量汇总时，只有 v3 活动数值警告对应片段经过完整原生 Word 输出认证，才将该片段的宽表分类作为诊断，避免它把数值警告的整体结论变成 `pending`。
- 历史 v3 正式报告保存了原 blocker 策略。持久化读取识别原正式策略并以该策略重算来源报告，仍逐值核对报告、摘要、绑定和 DOCX。修正计划仅消费稳定 finding ID。保留历史 v1 重放规则与原证据身份，无需数据迁移。
- 无效人工修正在原接纳前置验证拒绝，复用原子新代提交边界。在真实工作流回归中核对拒绝之后的新下载和原文件字节。
