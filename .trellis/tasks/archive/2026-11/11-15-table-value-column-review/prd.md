# 参数表数值列人工修正

## 目标

把 Word 里的重复手工调整前移到 Grid。校核人对照源 PDF 确定目标列，保存一份可复用的核定记录。同源重跑时用这份记录生成可复查的 Word。

## 当前基础

第一阶段在完整 `gs-008` 缓存中报告 23 处跨列阻断。已核定的两项是 `±5 µV → TYP` 和 `±100 µV → MAX`。原始错列、检测和审批阻断证据见[第一阶段验收](../11-15-value-column-span-check/prd.md)。`TableHeaderReview` 已提供[来源绑定与同源回放](../../../11-11-datasheet-quality-baseline-contracts/table-header-review.md)的先例。

## 需求

- R1 首版通过现有本地正式转换入口发起原排版回放，显式选用源 PDF、保留的 MinerU 结果包和校核 JSON。核定字段和来源绑定随本次 IR 保留。
- R2 只有 PDF、MinerU 内容列表、源表和目标原单元格都与记录吻合才接纳。来源过期、定位冲突或目标列无效时拒绝整批，并给出稳定原因。
- R3 支持单个原生表格片段内的数值跨列修正。跨列范围由并列数值列组成，校核人在其中选定单列，释放的列留空。同一行其余内容、其他行、单位、行列数及已有纵向合并保持原义。
- R4 保留原始 HTML、源 Grid 和原检测结果。正式交付证据核验实际 Word 后，只解除与本次已证明修正一一对应的跨列阻断。

## 验收

- [x] AC1（R1、R3）固定完整 `gs-008` 的原始输入，用同一记录连续回放到两个新输出路径。两个值在实际 Word 中只占各自目标列，释放槽位为空，`±75`、单位及合并结构正确。两次修正身份与观测到的表格结构一致。
- [x] AC2（R2）分别更换 PDF、修改可解析的 MinerU 内容列表字节、制造表/原格绑定过期。旧记录返回对应错误，新的输出路径没有本次 IR 或 DOCX。有效与无效记录混合时同样整批拒绝。
- [x] AC3（R4）完整样本的源报告保留原 23 项，交付证据仅结算两项，剩余 21 项同规则 blocker 继续阻断。两行精简对照中该规则的有效 blocker 为零。互换未修正文档与修正证据时，实际 Word 认证失败。
- [x] AC4（R1、R4）IR 与证据重读可重建相同修正。无记录输入及既有正常报告保持可读，原来的检测和交付门禁仍适用。

见[完整回放与定向验证记录](validation.md)。

## 首版边界

首版交付本地同源回放。任务台录入、线上同源重跑与结果接纳、翻译模式的人工修正另行评审。PDF 坐标匹配归入第三阶段。
