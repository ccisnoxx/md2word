# 参数值列跨列检测设计

## 规则判定

`app/services/tables/validator.py` 按 Grid 识别独立数值列，只扫描现有的非表头单值候选。普通文本单值支持 `e`/`E` 指数和指数正负号，保持单位及区间的原有判断语义。仅完整参考后缀 `REF` 和 `BSC` 表示显式共享参考值，`VREF` 等其他后缀按普通单值处理。

跨列单值统一使用 `table_value_column_span_ambiguous` 基本规则。历史 `.shared_limits` 规则、原因码和报告校验合同继续用于重读既有证据。正式渲染沿用默认规则严重度。

## 结果和复核

复用 `validate_document_tables`、表格证据聚合和本代结果凭据完成路径。表格 blocker 计入基础质量，审批和发布沿用各自的质量状态判定。固定 gs-008 HTML 片段用于验证实际生成的 DOCX 及两个入口的拒绝原因，测试复用本地任务装配与 MinerU 结果包替身。

对照输入仅把两个错误的跨列值放回源 PDF 确认的单列。检查 Word 实际布局列、内容和单位，保留同一行的其他值及 rowspan。系统内人工修正和 PDF 几何匹配属于后续阶段。
