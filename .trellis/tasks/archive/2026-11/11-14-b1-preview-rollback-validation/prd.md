# B1 回退候选与历史产物离线验证

## 目标

用一个基于当前 main 的可复现 B1 候选，验证停写新通用块锚点和页映射后，仍能生成主 DOCX 和预览、互读既有与候选产物，并恢复历史任务。

## 基线

规划基线为 main@4081b49e7b7fe18d41b4428321d4a33c206e6f37。RND-504／505 的回归记录可作为当前读者和预览生命周期的已有证据。历史 PR #9 的 B1 演练仅覆盖当时的候选，当前回退合同仍标为待验证。

## 验收标准

- [ ] **AC1 可复现候选。** 固定 main 源码提交、候选差异和构建输入。相同输入重建得到相同源码指纹，独立进程的模块加载路径和指纹均对得上。经正式任务链路完成新 DOCX 和预览，检查实际 DOCX XML 无新通用块锚点、元数据无新块锚点证明、预览 manifest 无新页映射。普通内容、公式及图片证据仍走原认证。
- [ ] **AC2 双向互读。** 候选读取有效旧 manifest（缺页映射）及当前带映射、带锚点的产物，正常构建读取候选停写后生成的产物。记录产物来源、对象身份和 SHA-256。兼容读取保留原产物字节和证据。验证已认证的预览在可选导航故障下仍可读，外层 manifest 或必需内容完整性失败继续拒绝。
- [ ] **AC3 三条历史恢复入口。** 在离线 file／SQLite 上，用同一候选验证历史结果发现、显式结果指针和已准备结果凭据。比对恢复前后的 DOCX、IR、manifest、已选文件身份、凭据与相关证据。覆盖有效、缺失或无效的可选证据，以及必需证据损坏的拒绝路径。确认可选失败局部降级、合法恢复不重渲染或替换历史主件、公开摘要和错误不泄露私有证据。
- [ ] **AC4 证据与结论。** 归档候选指纹、样本清单、互读与恢复矩阵及逐项结果。缺样本或未验证场景须标明，离线结论只适用于实测构建和环境。

## 范围边界

交付限候选构建与上述离线验证。生产回退演练另行验收，当前 B1 仍待验证。本轮只创建任务和规划，保留 en2zh-runtime-evidence.md 原样，不操作其他 worktree 或历史 PR，不实施、不重跑测试、不部署。
