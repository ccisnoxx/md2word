# 修正 MinerU v4 解析语言映射

## 需求

- 用户已确认先修正现有 MinerU v4 语言映射，实际请求与任务快照一致，并用公开中文和俄文 PDF 各运行一次真实解析。
- 中译英和中译俄使用 `ch`，俄译中验证 `east_slavic`，英译中使用 `en`。原文转换沿用 MinerU 配置的语言回退，已有合法供应商语言包可继续使用。
- 沿用当前 API、模型配置、公式/表格开关和 OCR 行为。本任务限于解析与 ZIP 验证。

## 验收

- [x] 新任务及新克隆快照的 MinerU 语言与首次上传请求中的 `language` 一致，覆盖有、无版本化资源快照的任务。Worker 按已绑定语言执行，术语重绑保留已有语言，历史记录继续可读、可恢复。
- [x] 定向回归覆盖中译英、中译俄、俄译中、英译中，以及原文转换和历史别名。
- [x] 中文、俄文各有一次真实 v4 解析记录。记录样本来源、请求语言、终态和 ZIP 中可确认的语言与技术标记，凭证与签名链接不进入证据。[验证记录](validation.md)
