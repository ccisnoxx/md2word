# TR-402：ProtectedTokenCodec 需求与验收

## 1. 目标与业务结果

为四种跨语言翻译提供可复用的纯内存技术 Token 编码/解码能力，使数字、单位、地址、位字段、信号、型号和公式不依赖 Prompt 自觉保留。目标是技术文本精确恢复、异常明确拒绝，同时让普通自然语言仍可翻译。

本子任务只交付 Codec 原语及其离线验证，不接入生产翻译调用；正式链路的完整性验证与回填接线属于 TR-403，不能把本任务完成写成生产技术完整性已经达标。

## 3. 范围

### 3.1 受保护内容

R1：定义可扩展的静态分类和确定性重叠规则，覆盖：

- 数字、科学计数法、比较符、正负号、公差、范围；
- 数字加单位、独立且明确的单位单元、复合单位；
- 十六进制地址及相邻位字段、独立位字段；
- 引脚、信号、变量、型号、封装、明确的协议/标准/技术缩写；
- URL、邮箱、版本号；
- 带明确边界的公式/LaTeX、可判定的技术赋值表达式；
- 源文已有的本 Codec/legacy 占位符字面量，以及本模块保留语法扫描器能识别的残缺前缀/变体。

R2：以完整有序文本批次分配占位符。每个出现位置独立编号，即使原始值相同也不共用占位符；批次内全局唯一，且不得与任一输入文本现有内容冲突。

R3：decode 必须先完成整批验证，再返回全部还原结果。缺失、重复、未知、改大小写、插空格、改括号、改编号、跨 item 移植等异常必须失败，不能部分解码、猜测修复或静默回退源文。

R4：保留源片段的原始字符，不 strip、不换单位、不纠正 OCR、不进行 Unicode 规范化。对于有效 UTF-8 输入，往返后字符串及其 UTF-8 字节完全一致；保留空格、换行、CRLF、NBSP、µ/μ、负号和组合字符差异。

R5：普通词不能因为首字母大写、全大写或单个拉丁字母就被保护。Typical、Reserved、High、Low、Input voltage、NOTE、普通中俄文等应保留为可翻译文本；未知缩写不能全部吞为技术 Token。单字母单位只在数值邻接或整个单元明确为单位时保护。

R6：encode/decode 是确定性纯函数；输入和映射不可被修改；不依赖随机数、时间、进程计数器、网络、文件、数据库、配置、语言模型或共享可变状态。

### 3.2 本任务与相邻任务的边界

本任务可以验证 Codec 返回边界中的 item 身份与 Token 所属关系，并用 fake Provider 模拟合法/非法响应。不得实现 Provider 响应解析、原始数字后验比对、翻译质量聚合、Worker 状态映射或批次重试/拆分。

明确范围外：真实模型调用；术语后验检查；caption/footnote 抽取与回填（TR-401）；TranslationIntegrityValidator 及生产接线（TR-403）；表格上下文（TR-404）；术语/语言 QA（TR-405）；部分失败/generation 编排（TR-406）；四方向正式样本门禁（TR-407）；Prompt/Profile/feature flag 修改；DOCX、API、DB、前端、发布功能。

## 4. 验收条件

| ID | 可观察结果 |
|---|---|
| AC1 | 每类正例命中正确原始片段；至少包含 25°C、0x0028、[4:0]、0x0028[4:0]、VCC1_VCO、OPA228、ZK7044、公式、URL、邮箱、版本号。 |
| AC2 | 重叠输入按固定顺序选取，不把地址/型号/公式切成裸数字，不重复或交叉覆盖；同输入重复执行得到完全相同的 items、分类、位置、占位符和映射。 |
| AC3 | 多 item、多次相同原文、超过 999 个 Token 均批次内唯一；源文包含 PH 字面量、本 Codec 前缀、候选占位符或恢复值时仍 collision-safe。 |
| AC4 | 对全部验收向量 decode(encode(batch).items, 对应映射)=batch，字符串和有效 UTF-8 字节保持率均为 100%；无 Token、空文本、空批次也可无损往返。 |
| AC5 | 缺失、重复、未知、篡改和跨 item 移植被拒绝；缺失/额外/重复/乱序 item 被拒绝；任一 item 失败时无部分成功结果；错误不泄漏原文。 |
| AC6 | 正常翻译可以修改非保护文字、在同 item 内移动完整占位符；只要该 item 的每个占位符仍恰好一次就精确恢复其技术值。跨 item 交换不通过。 |
| AC7 | 自然语言反例不被整词或整句保护；普通词周围出现技术 Token 时只保护技术跨度，所有未选跨度字符保持原样。 |
| AC8 | 使用既有 OPA228 最小 MinerU fixture 经正式 converter/抽取入口得到的文本运行 Codec roundtrip；不引入第二套解析或新的专有样本，不改变 DocumentIR 结构。 |
| AC9 | 输入/映射不可变、调用间无共享状态；fake Provider 可测试正常文字翻译与异常 Token 响应，零外部调用；正式 translator、legacy 和 direct 模式既有定向回归不变。 |
| AC10 | 文档与 Spec 清楚说明算法、错误、兼容和未接生产的边界；不修改相邻任务或冻结合同。 |

## 5. 权限、失败语义和数据边界

- Codec 为内部函数，无独立 HTTP 入口或新角色权限；不获取 secret，也不打开文件、下载链接或执行公式/URL。
- 原始映射只在调用方内存保存，不进入 Provider payload、普通审计、DB、事件或常规日志；本任务不新增 debug Artifact 导出入口。
- 非法调用输入和完整性失败以稳定的内部机器码及中文错误文本显式抛出；只允许 item ID/类别/计数等非正文诊断。不修改现有 HTTP error_code。
- 所有 item 验证通过后才允许返回解码结果。映射必须由 encode 产生并与该批次一起持有；本任务不提供映射持久化/跨任务复用协议。
- Codec 只保证已识别 Token 的字符级完整性，不判断译文语义、技术值移动后的语义关联或未识别自然语言内容是否正确。

- 一次只实现 TR-402，不提前实施其他任务；保持模块化单体，不引入微服务、Kafka、向量库或第二套转换流水线。
- 一个 DocumentJob 只有一份用户主 DOCX；其他语言使用新建/克隆任务。
- direct_pdf_to_word 不调用 AI Provider，不加载翻译 Prompt 或翻译术语集；不新增中文转中文 Prompt。
- MinerU 为唯一 PDF 解析入口，不新增 OCR 预检或多解析器路由。
- HTML 可解析时必须输出 Word 原生表格，不以截图作为默认简化。
- quality blocked 和翻译 unreviewed 可内部下载，但不得批准或发布；前端消费后端权威状态/available actions，不自行推断发布资格。
- 不新增双语 DOCX、在线 Word 编辑、在线修表、批量任务或知识库。
- 不得为通过测试削弱权限、审计、不可变发布、技术 Token、内容完整性或路径安全边界。
- 编码/解码纯函数且确定性；原始技术文本字节/字符级恢复；占位符不与源文现有文本冲突。
