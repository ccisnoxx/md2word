# Datasheet 题注脚注翻译与 Word 上标

## 目标

跨语言转换时，表格、图片及以 image 表示的图表题注和脚注应与正文一同翻译，并能在审核中定位原文、译文、所属对象和批次证据。源文档中的 `$^{(1)(2)}$` 应在 Word 中显示为可编辑的上标 `(1)(2)`。

本任务是「Datasheet 文档交付质量完善」的子任务。规划依据为 `main` 的 `ea16ebddd0739a67d3d7b5a56c59c80ecfcaab68`。同父任务下的质量基线提供样本和预审记录。

## 已核实的问题

- 当前抽取器只处理 `text`、`list_items` 和表格 HTML 文本节点。用含表题、表注、图题、图注的最小 IR 调用，只有表格 HTML 节点进入翻译。TR-401 的 `ae3e49ca` 和集成快照 `956be112` 保有抽取、回填实现，当前 `main` 不含该能力。[当前抽取器](../../../app/domains/translation/document_ir_translator.py#L554)
- 对照 RS2G04 Rev A.4 第 6 页的源 IR 与译后 IR，`block_0003` 的五条脚注、`block_0005` 的一条 8.2 说明和两条 JEDEC 脚注原样保留。8.2 说明在源 IR 还兼作该表的 `text`，两处走了不同翻译路径。温度条件处的标记位于独立上下文段落 `block_0003_context_0001.text`，共享公式渲染器将其判为 `invalid_syntax` 并降级。[预审记录](../11-11-datasheet-quality-baseline-contracts/issues.md#rs2g04-两稿共有的问题与表头差异) · [公式渲染器](../../../app/conversion/docx_rules/formula.py#L333)

## 需求

1. **翻译和回填。** 翻译表格及图片的非空题注和脚注。每个数组元素使用所属块、字段和原始索引定位。保留独立正文、数组空位、注释顺序和对象归属。同一显示内容存在已确认的派生别名时，翻译其权威位置，并同步派生值。
2. **完整性与审核。** 注释进入现有翻译批次、技术 Token 校验、结果汇总和调试审计。审核按同一稳定单元关联原文、译文及可用证据。表格注释绑定表本身，并保持单元格、表头和同行上下文的位置语义。
3. **历史任务。** 已持久化的旧批次、同一来源的重试和已完成产物继续按原抽取范围处理。历史审核只显示原有翻译证据。新翻译源件启用注释范围，缺项时按现有校验拒绝生成成功主件。
4. **脚注上标。** 在原位置使用 Word 原生上标显示可确定的纯脚注标记。一般数学继续走 OMML。无法解析的内容仍显示原式及质量提示。
5. **direct。** 保留注释原文及归属，保持翻译 Provider、Prompt、翻译术语和批次零调用。新生成的 direct DOCX 同样可以使用修复后的 Word 上标。

## 验收条件

| ID | 可观察结果 |
| --- | --- |
| AC1 抽取与回填 | 表题、表注、图片题注、图片脚注及图表注释各自进入目标列表。多条注释、数组空位及相同文本的独立位置以原下标区分。同一输入重复抽取顺序一致。示例 ID 为 `block_0017.captions.0000` 和 `block_0017.footnotes.0000`。既有真实正文、列表与 HTML 项 ID 保持稳定。派生别名同步回填，独立正文单独翻译。源 IR 及源账本保持原样。 |
| AC2 批次、技术完整性与兼容 | 新注释在根计划、批次结果、重试或拆分及最终回填中按同一范围校验。缺项、错项或破坏数字、单位、公式的结果无法登记成功译后 IR 或主 DOCX。带注释的旧源件和既有旧批次可按原范围恢复，旧审核取证仍成立。新范围的缺项或错误范围触发既有稳定错误，无法降为旧批次。 |
| AC3 表格及审核 | 题注和脚注归属正确的表格、图片或图表。表格注释没有单元格坐标，原单元格上下文与编号保留。调试和审核能以字段和下标定位同一单元并核实对应证据。独立内容即使译文相同也保留各自应显示的位置，原有确证的别名和续表归并仍可追溯。历史注释没有翻译证据时按原文展示。 |
| AC4 四方向与 direct | `en2zh`、`ru2zh`、`zh2en`、`zh2ru` 均通过正式应用入口的确定性 Provider 回归，逐方向验证所属 Profile、注释交付及指明的技术 Token。direct 的题注、脚注和技术文本逐项对账，并验证翻译资源和批次零调用。四方向的确定性测试证明应用链路覆盖，真实语言验收以实译证据为准。 |
| AC5 Word 上标及旧证据 | `$^{(1)(2)}$` 输出包含 `w:vertAlign w:val="superscript"` 的 `w:r`，文本为 `(1)(2)`，位置和编号与源一致，本处无降级提示。数学正例仍为 OMML，畸形和不支持的公式仍保真降级。新报告可持久化重读并拒绝上标或文字篡改。历史原式降级及报告仍可读取。 |
| AC6 RS2G04 第 6 页 | 用登记的同源 PDF 与 MinerU 结果生成新英译中产物。按源 PDF 抽查 8.1 五条脚注、8.2 使用说明和两条 JEDEC 脚注，确认应译内容、编号、适用条件、数字与单位，并核对温度条件后的 `(1)(2)`。对照源 IR、翻译项、目标 IR、OOXML 和审核证据。检查原生 ESD 表的网格、合并和已标注技术 Token。记录样本、源码和产物指纹，以及结构检查与人工语义审核的实际结果。 |

## 范围边界

沿用现有 Prompt/Profile、Provider、存储和发布合同。范围限于注释翻译及其关联证据、必要的 IR 和渲染兼容、纯脚注标记渲染。历史译后 IR、DOCX 和已发布件保留原登记。图片像素翻译、Word 脚注域、表头识别和续表算法改造、通用 TeX 语法扩展、生产切换与全量发布验收另行管理。RS2G04 外部服务处理只在原有样本授权与隔离环境范围内进行，专有原件、正文和生成产物保留在授权存放位置。
