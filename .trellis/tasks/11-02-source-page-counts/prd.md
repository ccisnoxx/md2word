# 源 PDF 页面统计

## 目标

回答“总共多少页、转换多少页、降级多少页”。统计对象是源 PDF 页，不是最终 Word 页。来自 2026-11-02 重新审查的修复优先级第 2 项。

## 需求

1. 已交付任务：`checks_v1.document_base.page_counts` 提供总页数、已转换页数、降级页数、过滤页数和统计依据。
2. 失败任务：`failure_diagnostic` 提供总页数和统计依据，继续给出首个失败页和受影响页，不提供“成功页数”。
3. 详情页展示上述信息；依据不完整时显示“至少 N 页”。

## 验收标准

- [x] 总页数 = 已转换 + 降级 + 过滤。
- [x] 无降级任务同样有统计；多页渲染降级后计数正确。
- [x] 无 `layout.json` 时依据为 `content_blocks`，有时为 `mineru_layout`。
- [x] 旧结果没有该字段时不报错，也不伪造数字。
- [x] 验证失败与渲染失败的诊断都带总页数；无法得知时为 `null`。

## 范围外

Word 物理页数、逐页状态明细、独立的 `conversion-page-report` 文件。逐页状态目前可由降级页列表得出，没有独立消费者。
